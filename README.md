## 📖 Overview

A bespoke interactive developer portfolio built by **[Chaitanya Selote](https://github.com/selotechaitanya-svg)**, Full Stack Developer & UI/UX Designer. 

Bridging the gap between software engineering and expressive visual design, this portfolio is built using **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS v4**. It features an audacious **Neo-Brutalist** visual identity combined with physics-inspired animations, HTML5 Canvas connectors, real-time coding metrics, and interactive Easter eggs.

> 🌐 **Live Website:** [https://chaitanyaportfoliov2.vercel.app/](https://chaitanyaportfoliov2.vercel.app/)

## ✨ Key Features & Interactive Innovations

### 🪢 1. Dual-Cable Hanging Projects Gallery
* **Physics Sway Simulation:** Cards hang suspended from twin overhead cables, each with individualized pendulum physics (`@keyframes sway-1` to `sway-8`) and unique thread lengths so movement remains organic.
* **Canvas-Rendered Connectors:** Uses HTML5 Canvas to dynamically draw tension threads and mechanical mounting points.
* **Interactive Drag & Modals:** Users can drag the cables and click on project cards to trigger full modal breakdowns with deep-dive technical overviews, tech pills, and live demo links.

### 🧗 2. Interactive Rope-Climbing Character
* **Proximity & Touch Interaction:** A custom-illustrated vector character hangs along the boundary between the Hero and About sections.
* **Directional Physics:** Hovering or tapping left/right triggers directional angular swing responses (`rotate(±3.5deg)` to `rotate(±4deg)`).

### 🖱️ 3. Tactile Particle Trail & Easter Egg "Cool Mode"
* **Custom Blue Pointer:** Neo-brutalist bold pointer with a crisp drop shadow across desktop devices.
* **Velocity-Based Star Particles:** A lightweight particle pool emits colorful star bursts when moving the cursor or dragging across touchscreens.
* **Secret "Cool Mode" Lens:** Toggle the Easter egg button to equip an interactive X-ray spyglass flashlight (`backdrop-filter: invert(1) hue-rotate(...)`) that reveals inverted colors and hidden visual contrast as you explore the page.

### 📊 4. Real-Time Coding Stats Dashboard
* **GitHub Activity Grid:** Replicates true GitHub commit heatmaps with intensity levels, streaks, and repository counts.
* **LeetCode Problem Solver:** Live performance breakdown of algorithm challenges solved across Easy, Medium, and Hard tiers.

### 💼 5. Career Timeline (`EXPERIENCE_LOG`)
* **Blueprint Dot-Grid Theme:** Industrial blueprint aesthetic with guide wires and pulsing status nodes marking milestones from Full-Stack Development to Graphic & Motion Design.

### 🫧 6. Dynamic Floating Skills Cloud
* **Autonomous Floating Bubbles:** Floating technology badges grouped across Frontend, Backend, UI/UX, and Engineering Tools with randomized multi-axis gentle float keyframes.

### 🧭 7. Hand-Drawn Roadmap & Vector Accents
* **Organic Bezier Paths:** Hand-drawn treasure-map trails, compass stars, and celestial markers running subtly through background layers.

### 📱 8. 100% Responsive & Accessible
* **Adaptive Breakpoints:** Finely tuned scaling from ultra-wide displays down to compact mobile viewports.
* **Smart Auto-Hiding Navbar:** Features a live reading progress indicator bar and section scroll-spy.
* **Reduced Motion Support:** Honors user accessibility preferences (`prefers-reduced-motion: reduce`) to freeze sway and float cycles when requested.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine.

### Prerequisites

Ensure you have the following installed:
* **Node.js**: `v18.18.0` or higher (Node 20+ recommended)
* **npm**, **pnpm**, or **yarn**

### 1. Clone the Repository

```bash
git clone https://github.com/selotechaitanya-svg/chaitanyaportfoliov2.git
cd chaitanyaportfoliov2
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser to view the application.

> *Note: The dev script runs on port `3001` by default.*

### 4. Build for Production

To create an optimized production build:

```bash
npm run build
npm run start
```

## ⚡ Performance & Optimization Highlights

* 🏎️ **Zero Heavy Animation Bloat:** 100% lightweight vanilla HTML5 Canvas + native CSS keyframe transforms—zero heavy runtime physics bundles, ensuring rock-solid 60 FPS performance.
* 🖼️ **Next-Gen Images:** High-resolution assets served through Next.js automatic image optimization (`next/image`) with responsive sizes, WebP formatting, and priority preloading.
* 🔤 **Zero Font Layout Shift:** Self-hosted Google Fonts (`Geist` and `Geist Mono`) preloaded at build time via `next/font`.
* 🎯 **Strict TypeScript:** Strongly typed props, project interfaces, and coordinate geometry calculations.
